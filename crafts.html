1🛠️ Forgeron

Chaîne « clous »

  1. 📦 Entrées: FreezeBar_iron ⚙️ Station: FreezeFurnace_Static (fourneau)
    → 🏁 Résultat: Heritier_lingot_de_fer_chaud
  2. 📦 Entrées: Heritier_lingot_de_fer_chaud ⚙️ Station: FreezeAnvil_Static (enclume)
    → 🏁 Résultat: Heritier_boule_de_fer_chaud
  3. 📦 Entrées: Heritier_boule_de_fer_chaud ⚙️ Station: FreezeAnvil_Static
    → 🏁 Résultat: Heritier_fer_taille_clous_chaud
  4. 📦 Entrées: Heritier_fer_taille_clous_chaud ⚙️ Station: rag_baseitems_waterbarrel (trempe)
    → 🏁 Résultat: Heritier_fer_taille_clous_refroidi
  5. 📦 Entrées: Heritier_fer_taille_clous_refroidi ⚙️ Station: FreezeAnvil_Static
    → 🏁 Résultat: Nail
  6. 📦 Entrées: Nail + Paper
    → 🏁 Résultat: NailBox

Chaîne « hachette (partie métal) »

  1. 📦 Entrées: Heritier_boule_de_fer_chaud 🧰 Outil: Hammer
    → 🏁 Résultat: tête de hache (chaud, mal taillée)
  2. 📦 Entrées: tête de hache (mal taillée) ⚙️ Station: FreezeGrindingStone_Static (meule)
    → 🏁 Résultat: tête de hache (chaud)
  3. 📦 Entrées: tête de hache (chaud) ⚙️ Station: rag_baseitems_waterbarrel
    → 🏁 Résultat: tête de hache (refroidie)

Chaîne « marteau »

  1. 📦 Entrées: Heritier_boule_de_fer_chaud ⚙️ Station: FreezeAnvil_Static
    → 🏁 Résultat: tête de marteau (chaude, mal taillée)
  2. 📦 Entrées: tête de marteau (chaude, mal taillée) ⚙️ Station: rag_baseitems_waterbarrel
    → 🏁 Résultat: tête de marteau (mal taillée, refroidie)
  3. 📦 Entrées: tête de marteau (mal taillée) ⚙️ Station: FreezeGrindingStone_Static
    → 🏁 Résultat: tête de marteau (affûtée)
  4. 📦 Entrées: Heritier_Manche + tête de marteau
    → 🏁 Résultat: Hammer
Le manche peut être fabriqué côté Menuisier (voir plus bas).

Chaîne « scie »

  1. 📦 Entrées: Heritier_lingot_de_fer_chaud ⚙️ Station: FreezeAnvil_Static
    → 🏁 Résultat: Heritier_baton_de_fer_chaud
  2. 📦 Entrées: Heritier_baton_de_fer_chaud 🧰 Outil: Whetstone (pierre à aiguiser)
    → 🏁 Résultat: HandSaw

Chaîne « pierre à aiguiser »

  1. 📦 Entrées: Stone ⚙️ Station: FreezeGrindingStone_Static
    → 🏁 Résultat: SmallStone
  2. 📦 Entrées: SmallStone ⚙️ Station: FreezeGrindingStone_Static
    → 🏁 Résultat: StoneKnife
  3. 📦 Entrées: StoneKnife ⚙️ Station: FreezeGrindingStone_Static
    → 🏁 Résultat: Whetstone
